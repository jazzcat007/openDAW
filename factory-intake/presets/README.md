# Factory Preset Intake

Starter presets generated by `scripts/generate-presets.mjs`.

## Layout
```
factory-intake/presets/
  index.json
  *.odp
  MANIFEST.md
  README.md
```

## How to ship
1. Copy `factory-intake/presets/` to `/data/factory/presets/` on the media volume.
2. Keep `OPENDAW_FACTORY_OFFLINE_ONLY=true` in production.
3. The factory preset loader expects `presets/index.json` to be a flat array of `PresetMeta` objects and `.odp` files named by UUID.

- Clean Piano — instrument: Soundfont GeneralUser GS
- Synth Bass — instrument: Vaporisateur monophonic bass

Asset-dependent presets (Guitar Cab Convolver, Lo-Fi Sampler, Clean Piano, Orchestral Sketch) require the matching samples/soundfonts to be imported first. See `factory-intake/import-plan.md`.
